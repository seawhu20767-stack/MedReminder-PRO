กำลังเปิดอยู่ในหน้าต่างตัวอย่าง (Preview Frame)

เบราว์เซอร์จะไม่อนุญาตให้ติดตั้งแอปจากหน้าต่าง Preview โดยตรง ให้กดปุ่ม "ดาวน์โหลดไฟล์เว็บ (.html)" ด้านล่าง แล้วนำไปเปิดผ่านลิงก์เว็บ (เช่น Netlify Drop / Tiiny.host) เพื่อกดเพิ่มลงหน้าจอโฮมบนมือถือครับ

ขั้นตอนติดตั้งบน Android (Google Chrome):

  1. 1 เปิดหน้าเว็บนี้ในแอป Google Chrome
  2. 2 แตะที่ปุ่ม จุด 3 จุด () บริเวณมุมขวาบนของเบราว์เซอร์
  3. 3 เลือกเมนู "ติดตั้งแอป" (Install app) หรือ "เพิ่มลงในหน้าจอหลัก" แล้วกดยืนยัน

ขั้นตอนติดตั้งบน iPhone / iPad (Safari):

  1. 1 เปิดหน้าเว็บนี้ด้วยเบราว์เซอร์ Safari
  2. 2 แตะปุ่ม แชร์ (Share ) ที่แถบเมนูด้านล่าง
  3. 3 เลื่อนลงและเลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen ) จากนั้นกด "เพิ่ม"

ขั้นตอนติดตั้งบนคอมพิวเตอร์ (Chrome / Edge):

  1. 1 สังเกตที่แถบ Address Bar ด้านขวาบนของเบราว์เซอร์
  2. 2 คลิกที่ไอคอน ติดตั้งแอป ( / Install) แล้วกด "ติดตั้ง"
  3. 3 แอปจะถูกสร้างทางลัดบน Desktop และเปิดใช้งานเป็นหน้าต่างแอปแยกได้ทันที

บันทึกไฟล์เว็บไปเปิดติดตั้งบนมือถือ
